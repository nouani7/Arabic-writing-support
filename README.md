# Arabic Writing Support Tool

A Windows utility that enables Arabic text writing in applications that do not natively support Arabic text shaping or right-to-left (RTL) text direction.

Simply type or paste your Arabic text, convert it into the appropriate format, and copy the result to use it in applications that have limited or no Arabic language support.

It is especially useful when working with older versions of Adobe Photoshop, graphic design software, video editing applications, and other programs that do not properly handle Arabic text.

## Features

- **Arabic Text Support:** Converts Arabic text into properly shaped characters with correct letter connections.
- **Right-to-Left Support:** Handles Arabic text direction to improve its appearance in unsupported applications.
- **Arabic Diacritics:** Supports Arabic diacritical marks (Tashkeel), with the option to enable or disable them.
- **Kashida Support:** Extends Arabic words using Kashida (ـ) to improve text alignment and appearance.
- **Text Formatting:** Automatically splits text into lines based on the specified number of words.
- **Line Width Adjustment:** Supports extending lines to a target width using Kashida.
- **Numeral Formatting:** Supports Arabic and Western (English) numerals.
- **Bilingual Interface:** Switch between Arabic and English application interfaces.
- **Automatic Clipboard Copy:** Automatically copies the converted text to the clipboard.
- **Simple Workflow:** Type or paste, convert, and use your Arabic text directly in your preferred application.

## How to Use

1. Open Arabic Writing Support Tool.
2. Type or paste your Arabic text into the input area.
3. Select your preferred language and formatting options.
4. Convert the text into the compatible Arabic format.
5. The converted text is automatically copied to the clipboard.
6. Paste it into your target application.

# أداة دعم الكتابة باللغة العربية

أداة لنظام Windows تتيح الكتابة باللغة العربية داخل البرامج التي لا تدعم تشكيل الحروف العربية أو اتجاه الكتابة من اليمين إلى اليسار (RTL) بشكل صحيح.

يمكنك ببساطة كتابة النص العربي أو نسخه ولصقه داخل الأداة، ثم تحويله إلى الصيغة المناسبة لاستخدامه في البرامج التي تفتقر إلى دعم اللغة العربية.

تُعد الأداة مفيدة بشكل خاص عند العمل على الإصدارات القديمة من Adobe Photoshop وبرامج التصميم وتحرير الفيديو وغيرها من التطبيقات التي لا تتعامل مع النصوص العربية بشكل صحيح.

## المميزات

- **دعم الكتابة العربية:** تحويل الحروف إلى أشكالها الصحيحة مع ضمان اتصال الحروف.
- **اتجاه الكتابة:** معالجة اتجاه النص العربي من اليمين إلى اليسار.
- **التشكيل:** دعم الحركات والتشكيل العربي مع إمكانية تفعيله أو تعطيله.
- **الكشيدة:** تمديد الحروف باستخدام الكشيدة لتحسين مظهر النص وتنسيقه.
- **تقسيم النص:** تقسيم النص تلقائياً إلى أسطر حسب عدد الكلمات المحدد.
- **ضبط عرض الأسطر:** إمكانية تمديد الأسطر باستخدام الكشيدة للوصول إلى عرض مستهدف.
- **الأرقام:** إمكانية الاختيار بين الأرقام العربية والإنجليزية.
- **واجهة متعددة اللغات:** إمكانية تغيير واجهة البرنامج بين العربية والإنجليزية.
- **النسخ التلقائي:** نسخ النص المحوّل تلقائياً إلى الحافظة (Clipboard).
- **سهولة الاستخدام:** اكتب أو الصق النص، حوّله، ثم استخدمه مباشرة في البرنامج المطلوب.

## طريقة الاستخدام

1. افتح أداة دعم الكتابة باللغة العربية.
2. اكتب النص العربي أو انسخه والصقه داخل الأداة.
3. اختر اللغة وإعدادات التنسيق المناسبة.
4. حوّل النص إلى الصيغة المتوافقة مع البرنامج المستهدف.
5. سيتم نسخ النص المحوّل تلقائياً إلى الحافظة.
6. الصق النص داخل البرنامج الذي تريد استخدامه.

## البرامج المستهدفة

تعمل الأداة على مساعدة المستخدمين في التعامل مع البرامج التي لا تدعم تشكيل الحروف العربية أو اتجاه الكتابة بشكل صحيح، ومنها:

- الإصدارات القديمة من Adobe Photoshop.
- برامج التصميم والجرافيك.
- برامج تحرير ومونتاج الفيديو.
- التطبيقات الأخرى التي تعاني من ضعف دعم اللغة العربية.
