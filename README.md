# Arabic Writing Support Tool

**Make Arabic text work in applications that do not support Arabic properly.**

Arabic Writing Support is a simple tool that helps you write Arabic text in applications that do not support Arabic letter shaping or Right-to-Left (RTL) text direction.

You can use it directly online through your web browser or download the Windows application to work offline.

## Choose How to Use

### 1. Use Online – No Installation Required

Open the tool directly in your browser and start converting Arabic text instantly.

**[Open Arabic Writing Support Online](https://nouani7.github.io/Arabic-writing-support/)**

- No installation required.
- Works directly in your web browser.
- Easy access from your computer.
- Requires an internet connection.

### 2. Download for Windows – Work Offline

Download the Windows application to use Arabic Writing Support directly from your computer, even without an internet connection.

**[Download Arabic Writing Support for Windows](https://github.com/nouani7/Arabic-writing-support/raw/refs/heads/main/Arabic%20Writing%20Support.exe)**

- No browser required.
- Works without an internet connection after downloading.
- Run the application directly on Windows.
- Suitable for everyday use.

## Features

- **Arabic Text Shaping:** Converts Arabic letters into correctly connected forms.
- **Right-to-Left Support:** Helps display Arabic text in the correct direction.
- **Arabic Diacritics:** Supports Tashkeel, with the option to enable or disable it.
- **Kashida Support:** Extends Arabic words using Kashida (ـ) for better text alignment.
- **Automatic Text Formatting:** Splits text into lines based on a specified number of words.
- **Line Width Adjustment:** Extends lines using Kashida to reach a target width.
- **Numeral Formatting:** Supports Arabic and Western (English) numerals.
- **Bilingual Interface:** Switch between Arabic and English.
- **Automatic Clipboard Copy:** Copies the converted text automatically.
- **Simple Workflow:** Type, convert, and paste your text into the target application.

## How to Use

1. Open the online tool or the Windows application.
2. Type or paste your Arabic text.
3. Choose your preferred language and formatting options.
4. Convert the text.
5. The converted text is automatically copied to the clipboard.
6. Paste it into your target application.

## Compatibility

Designed to help with applications that have limited Arabic language support, including:

- Older versions of Adobe Photoshop.
- Graphic design and image editing software.
- Video editing applications.
- Other programs that do not properly support Arabic text.

# أداة دعم الكتابة باللغة العربية

**اجعل النصوص العربية تعمل بشكل صحيح في البرامج التي لا تدعم اللغة العربية.**

أداة بسيطة تساعدك على كتابة النصوص العربية داخل البرامج التي لا تدعم تشكيل الحروف العربية أو اتجاه الكتابة من اليمين إلى اليسار (RTL) بشكل صحيح.

يمكنك استخدام الأداة مباشرة عبر الإنترنت من خلال المتصفح، أو تحميل نسخة Windows واستخدامها على جهازك دون الحاجة إلى اتصال بالإنترنت.

## اختر طريقة الاستخدام

### 1. الاستخدام عبر الإنترنت – بدون تثبيت

يمكنك فتح الأداة مباشرة من المتصفح والبدء في تحويل النصوص العربية دون الحاجة إلى تحميل أي برنامج.

**[استخدام الأداة أونلاين](https://nouani7.github.io/Arabic-writing-support/)**

- لا تحتاج إلى تثبيت أي برنامج.
- تعمل مباشرة من متصفح الإنترنت.
- سهلة الوصول والاستخدام.
- تتطلب اتصالاً بالإنترنت.

### 2. تحميل نسخة Windows – للعمل بدون إنترنت

يمكنك تحميل نسخة Windows وتشغيل الأداة مباشرة على جهاز الكمبيوتر، واستخدامها حتى عند عدم توفر اتصال بالإنترنت.

**[تحميل البرنامج لنظام Windows](https://github.com/nouani7/Arabic-writing-support/raw/refs/heads/main/Arabic%20Writing%20Support.exe)**

- لا تحتاج إلى متصفح.
- تعمل بدون إنترنت بعد تحميلها.
- يمكن تشغيلها مباشرة على Windows.
- مناسبة للاستخدام اليومي.

## المميزات

- **تشكيل الحروف العربية:** تحويل الحروف إلى أشكالها الصحيحة مع ضمان اتصالها.
- **اتجاه الكتابة:** معالجة اتجاه النص العربي من اليمين إلى اليسار.
- **التشكيل والحركات:** دعم الحركات العربية مع إمكانية تفعيلها أو تعطيلها.
- **الكشيدة:** تمديد الكلمات باستخدام الكشيدة (ـ) لتحسين مظهر النص وتنسيقه.
- **تقسيم النص:** تقسيم النص تلقائياً إلى أسطر حسب عدد الكلمات المحدد.
- **ضبط عرض الأسطر:** تمديد الأسطر باستخدام الكشيدة للوصول إلى عرض محدد.
- **تنسيق الأرقام:** دعم الأرقام العربية والإنجليزية.
- **واجهة متعددة اللغات:** إمكانية التبديل بين العربية والإنجليزية.
- **النسخ التلقائي:** نسخ النص المحوّل تلقائياً إلى الحافظة.
- **سهولة الاستخدام:** اكتب النص أو الصقه، ثم حوّله وانسخه إلى البرنامج المطلوب.

## طريقة الاستخدام

1. افتح النسخة الإلكترونية أو برنامج Windows.
2. اكتب النص العربي أو انسخه والصقه داخل الأداة.
3. اختر اللغة وإعدادات التنسيق المناسبة.
4. اضغط على زر تحويل النص.
5. سيتم نسخ النص المحوّل تلقائياً إلى الحافظة.
6. الصق النص داخل البرنامج الذي تريد استخدامه.

## البرامج المستهدفة

تساعد الأداة على الكتابة باللغة العربية في البرامج التي تعاني من ضعف دعم اللغة العربية، ومنها:

- الإصدارات القديمة من Adobe Photoshop.
- برامج التصميم والجرافيك وتحرير الصور.
- برامج تحرير ومونتاج الفيديو.
- التطبيقات الأخرى التي لا تدعم تشكيل الحروف العربية بشكل صحيح.
